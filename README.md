# ⚡ 雷霆战机 - 2D 飞行射击联机游戏

带账号系统、好友系统、战绩记录和实时联机对战的开源网页小游戏。

## 🚀 快速开始

```bash
cd D:/zyue/test
npm install     # 首次运行
npm start       # 或 node server.js
```

浏览器打开 **http://localhost:3000**

## ✨ 功能

- **账号系统**：登录 / 退出 / 会话保持（刷新不掉线）
- **战绩记录**：每次游玩自动记录得分、击落数、模式（单人/联机）
- **排行榜**：全部账户最高分排行 + 在线状态
- **好友系统**：按 UID 添加好友，实时显示好友在线状态
- **邀请对战**：好友在线时可直接邀请，对方弹窗接受后自动进入同一局
- **开房间对战**：传统房间码方式（复制邀请链接分享）
- **游戏内容**：5 级火力、多类型敌机、Boss 战、全屏炸弹、粒子特效

## 🎮 操作

- 鼠标 / 方向键 / WASD 移动战机
- 自动开火，空格或鼠标点击释放炸弹
- ESC 暂停

## ☁️ 部署到线上（免费）

### 方式一：Render（推荐，最省事）
1. 把本目录推送到 GitHub 仓库
2. 登录 [render.com](https://render.com) → New → **Blueprint**
3. 选择仓库，自动读取 `render.yaml`，一键部署

### 方式二：Railway / Fly.io / Glitch 等
已内置 `Dockerfile`，任何支持 Docker 的平台直接部署即可。

### 部署后
用部署域名替换本地地址即可，例如 `https://你的域名/`。
首次登录用上面任一测试账户即可。

> ⚠️ 联机功能依赖 HTTPS（WebRTC 需要安全上下文），Render/Railway 均自动提供。

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `server.js` | Node.js 后端（登录/好友/战绩/在线状态/邀请信令） |
| `index.html` | 前端（游戏引擎 + UI，单文件） |
| `data.json` | 运行时自动生成，存储昵称/战绩/好友关系 |
| `package.json` | 依赖与启动脚本 |
| `render.yaml` | Render 一键部署配置 |
| `Dockerfile` | Docker 部署配置 |
